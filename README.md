# Aula inserção de Mídias Digitais em HTML

Objetivo: Aprender a incorporar elementos multimídia (áudio e vídeo) em páginas web, tanto de forma nativa quanto por meio de plataformas externas.

O que foi abordado:

Como utilizar tags HTML para reproduzir mídias locais.

Como fazer o embed (incorporação) de vídeos do YouTube em um site.

Tecnologia: HTML
